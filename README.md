# kcuevasb.github.io

CV interactivo de Kepa Cuevas Barrasa — Software Engineer.

Tema Matrix / pixel art: lluvia de código en `<canvas>`, boot de terminal, acordeón de
experiencia, barras de skills animadas y una consola interactiva con easter eggs.

Sin frameworks ni build step: HTML + CSS + JS puro, pensado para GitHub Pages.

- `index.html` — estructura y contenido
- `styles.css` — tema visual (Matrix + pixel art + CRT)
- `script.js` — lluvia de matrix, boot, interacciones, consola

## Desarrollo local

Cualquier servidor estático sirve, por ejemplo:

```bash
npx serve .
```

Construido con [Claude Code](https://claude.com/claude-code).
