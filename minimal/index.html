04 — Proyectos autodidactas, con IA

Fuera de la oficina no dejo de programar, solo cambio de problema. Proyectos reales, terminados y en uso — empezando por mí mismo — construidos en stacks que no toco en el trabajo, con IA como copiloto para acelerar la curva de aprendizaje, no para sustituirla. El código es privado; lo que se puede enseñar es el criterio detrás.

  • StiEx Android nativo

    Exportar e importar stickers de WhatsApp sin rootear el móvil. Lee la carpeta protegida vía Storage Access Framework, convierte fotos en stickers respetando los límites reales de WhatsApp, y los publica con la API oficial de terceros.

    Kotlin · Jetpack Compose · SAF · WebP

  • gim-app Expo / React Native

    Entrenamiento y nutrición de principio a fin. Genera rutinas con un algoritmo basado en reglas, guía la sesión con temporizador de descanso, y controla la despensa calculando cuándo se agota cada producto sin histórico redundante. Auth y datos en Supabase con Row Level Security.

    Expo · React Native · TypeScript · Supabase · PostgreSQL

  • cartelera-app en producción

    Sustituto personal de TV Time cuando cerró: series y películas con login Google, multiusuario real, amigos, chat y feed de actividad. Arquitectura hexagonal desde cero, caché con Caffeine.

    Java · Spring Boot · Arq. Hexagonal · PostgreSQL · Render

    Ver en producción →

  • PhotoSwipe Expo / React Native

    Vaciar el carrete acumulado sin fricción: revisar la galería a golpe de swipe, decidiendo en un gesto qué foto se queda y cuál se borra.

    Expo · React Native · TypeScript

  • Bounce Android nativo

    El patrón híbrido nativo + WebView llevado en serio: interfaz en HTML/JS reutilizable, con integración nativa de Android cuando el navegador embebido se queda corto.

    Kotlin · WebView · HTML/JS
