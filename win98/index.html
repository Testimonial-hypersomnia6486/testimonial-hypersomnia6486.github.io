Proyectos autodidactas con IA

          
Fuera de la oficina no dejo de programar, solo cambio de problema. Proyectos reales, terminados y en
          uso — empezando por mí mismo — construidos en stacks que no toco en el trabajo, con IA (Claude Code)
          como copiloto para acelerar la curva de aprendizaje, no para sustituirla. El código es privado; lo que
          se puede enseñar es el criterio detrás. Selecciona un archivo a la izquierda.

        

        

          
StiEx · Android nativo

          
Exportar e importar stickers de WhatsApp sin rootear el móvil ni depender de apps de terceros dudosas.
          Lee la carpeta protegida de WhatsApp vía Storage Access Framework, convierte fotos en stickers respetando
          al milímetro los límites reales de WhatsApp (≤30 por pack, ≤100KB estático / 500KB animado) y los publica
          con la API oficial de terceros.

          
Kotlin · Jetpack Compose · SAF · WebP

        

        

          
gim-app · Expo / React Native

          
Entrenamiento y nutrición de principio a fin, no una hoja de cálculo con esteroides. Genera rutinas con
          un algoritmo basado en reglas sin depender de una IA para algo que no la necesita, guía la sesión con
          temporizador de descanso, y lleva un control de despensa que calcula cuándo se agota cada producto sin
          guardar un histórico que nadie va a mirar. Auth y datos en Supabase con Row Level Security de verdad.

          
Expo · React Native · TypeScript · Supabase · PostgreSQL

        

        

          
cartelera-app · Java · Spring Boot · en producción

          
Sustituto personal de TV Time cuando cerró: seguimiento de series y películas con login Google,
          multiusuario real, amigos, chat y feed de actividad. Arquitectura hexagonal desde cero, caché con
          Caffeine, guardado incremental de biblioteca. En producción, con usuarios reales que no son yo.

          
Java · Spring Boot · Arq. Hexagonal · PostgreSQL · Docker · Render

          ▶ ver en producción
        

        

          
PhotoSwipe · Expo / React Native

          
Vaciar el carrete acumulado sin fricción: revisar la galería a golpe de swipe, como un juego de cartas,
          decidiendo en un gesto qué foto se queda y cuál se borra.

          
Expo · React Native · TypeScript

        

        

          
Bounce · Android nativo

          
El patrón híbrido nativo + WebView llevado en serio: interfaz en HTML/JS reutilizable entre pantallas,
          con la integración nativa de Android por debajo cuando el navegador embebido se queda corto.

          
Kotlin · WebView · HTML/JS

        

        

          
este-sitio.html · construido con Claude Code

          
Sí, esta página también cuenta. El aprendizaje autodidacta no se detiene en el móvil — sigue en
          frontend, en desplegar sin fricción, y en cómo integrar IA en el propio flujo sin que sea solo
          autocompletado.
